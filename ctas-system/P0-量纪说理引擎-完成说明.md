# P0 量纪说理引擎 — 完成说明

> 对应需求：审理报告「四、定性量纪意见」原是一句空话"依据相关纪律条款，建议给予相应处分"，与实际业务贴合度不够。本项把这句话升级为**结构化量纪说理稿**。

## 做了什么

把审理报告的"灵魂"——定性量纪说理——从空话变成可复核的结构化成稿：

```
定性分析 → 真实法条依据（条号+条文）→ 量纪档次区间 → 从轻/从重情节说理 → 处理意见
```

**设计原则（与项目既有证据链/程序合规引擎一致）**
- 系统能依据在案事实与法规条文自动推导的，给确定说理；
- 凡须人工裁量的（最终处分档次），一律标注"须经审理组集体审议"，**绝不臆断结论**；
- 离线、确定性引擎，**不依赖 LLM / RAG 向量检索**，保证可审、可控、不增事实。

## 本轮打磨（续）

1. **党纪政务"双区间"匹配**：此前"建议量纪区间"只出党纪五档，现公职人员案件同时给出政务处分区间（警告/记过/记大过/降级/撤职/开除），落实"党纪政务处分相匹配"；成稿（三）量纪档次与（六）处理意见均引用政务区间。
2. **条款库拓宽**：新增第九十九条（借用钱款）、第一百条（婚丧喜庆）、第一百零五条（离职兼职）、第一百一十二条（占用公物）、第一百一十四条（滥发津补贴）、第七十四条（管党治党不力）共 6 条，条文严格取自语料 `jjjc.txt`；兜底查找改为按条号定位。
3. **误判修复**：第一百一十四条初版用"补贴"泛化词导致"财政补贴审批"误命中，已收紧为特异性关键词。
4. **人工认定情节（深度打磨）**：自动识别从轻/从重原只读两个字段，漏掉主动交代、检举立功、强迫唆使、串供等真实情节。现提供标准情节目录（从轻 6 项 + 从重 5 项，引《条例》第十七/二十条、政务处分法第十一/十三条），审理组在卡片中**勾选即并入说理稿与报告**，标注"经审理组人工认定"，与自动项自动去重——真正落实"系统不替代人工结论"。已在 trial 4 端到端验证：勾选"主动交代"后，报告（四）段出现"主动交代…（经审理组人工认定）（依据第十七条（一））"。
5. **涉案财物处置结构化成段（深度打磨）**：原（五）涉案财物只有一行占位，现升级为四段式结构清单——① 在案数额（自动识别，字段→处置意见文本→案情文本三级兜底）；② 承办人已提处置意见（动作识别+原文引用）或按问题性质给**建议方向并标注"须审理组确认"**；③ 涉嫌犯罪移送提示（在案材料有移送迹象而处置意见未含移送时亮红）；④ 处置依据（《条例》第四十三条 + 政务处分法第二十五条、第二十七条，条文严格取自语料）。前端卡片同步新增"涉案财物处置"小节。

## 报告结构（2026-10-24 起，对标中纪委七章）

生成审理报告时自动按《监督执纪工作规则》第五十六条结构重组：

```
标题
一、被审查调查人基本情况
二、案件来源及审理经过（审计留痕聚合生成）
三、主要违纪违法事实（全文）
四、证据情况（证据链校验 + 物证清单）
五、定性量纪意见（定性→法条→量纪区间→从轻从重）
六、涉案财物情况（数额/处置意见/移送提示/法条依据）
七、处理意见与建议（含尾部署名占位）
八、类案参考（如选用）
```
